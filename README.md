# Rock Paper Scissors Game

A simple browser-based Rock Paper Scissors game built with **HTML**, **CSS**, and **JavaScript**. Choose rock, paper, or scissors to play against the computer; the game displays each round's result and keeps score.

## Features

- Player choices: Rock, Paper, and Scissors
- Random computer selection
- Instant round result messages
- Running player, computer, and draw scores
- Responsive, easy-to-use interface

## How to Run

1. Download or clone this project.
2. Open `index.html` in any modern web browser.
3. Select Rock, Paper, or Scissors to start playing.

No installation or server is required.

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Matching choices result in a draw
